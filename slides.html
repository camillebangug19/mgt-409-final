The guidance exists. Nothing tells a family “here's where you stand — do these three things.”

What's new

  1. One conversation for the whole household — kids, older adults, mobility, medical equipment and pets together
  2. A score out of 10 that never marks you down for what doesn't apply to you
  3. Three steps, free ones first, each showing “+X points”, like a safe-driving discount
  4. Every tip links to an official source — the app is built so it can't invent advice
  5. Success = steps completed, not page views

How it works

The AI handles the conversation. Plain code does the scoring and checks every link — cheaper, testable, accurate. Model: gpt-6-luna via Portkey.

A real run

Persona: older adult on home oxygen, no car, Florida apartment — 25 turns, scored 5.0/10, top steps: transportation-plan, backup-power, meds-7day. Matches what the unit tests predict without the model.

Safety

The model can't change state. It can only call a schema-validated record_answer, and only surface steps the Python ranker chose.

RiskDefence
